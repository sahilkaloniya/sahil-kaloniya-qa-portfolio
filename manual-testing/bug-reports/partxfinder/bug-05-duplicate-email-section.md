# PXF_026 — Email Section Is Displayed Twice

## Bug Type
Functional

## Severity
Moderate

## Priority
High

## Environment
Mobile App

## Description

The email section was displayed twice in the relevant user interface instead of appearing as a single email section.

## Steps to Reproduce

1. Open the PartXFinder application.
2. Navigate to the screen containing the email information.
3. Observe the email section.
4. Check whether the email field/section is displayed more than once.

## Expected Result

The email section should be displayed only once with the correct information and layout.

## Actual Result

The email section was displayed twice.

## Impact

Duplicate email sections can confuse users, make the interface appear inconsistent, and may create uncertainty about which field should be used.
