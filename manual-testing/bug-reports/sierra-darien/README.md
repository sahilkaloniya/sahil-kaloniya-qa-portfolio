# Sierra Darien — Bug Reports

## Testing Scope

Functional and UI/UX testing of an e-commerce application across supported browsers and devices.

## QA Activities

- Functional testing
- UI/UX testing
- Regression testing
- Cross-browser testing
- Cross-device testing
- Defect reproduction
- Fix verification
- Positive, negative and edge-case testing

## Project Coverage

Testing included customer-facing and administrative workflows, with focus on functionality, usability, navigation, validation and consistent behavior across supported environments.

## Bug Reports

Selected real-world defects identified during testing will be documented in this section using a structured format.

Each report includes:

- Bug title
- Severity
- Priority
- Environment
- Steps to reproduce
- Expected result
- Actual result
- Testing type
- Status

## Confidentiality

Project-specific URLs, credentials, private screenshots, internal references and other confidential information are excluded or generalized for public presentation.
