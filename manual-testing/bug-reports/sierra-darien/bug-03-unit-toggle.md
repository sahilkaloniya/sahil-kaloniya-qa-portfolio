# SD_012 — Unit Toggle Does Not Change UI

## Bug Type
Functional

## Severity
Major

## Priority
Medium

## Environment
Desktop / Web

## Description

The CMS/Inches unit toggle did not produce any visible change in the UI when used.

## Steps to Reproduce

1. Navigate to the affected collection page.
2. Locate the CMS/Inches unit toggle.
3. Select or switch the unit option.
4. Observe the UI after changing the selection.

## Expected Result

Changing the unit selection should update the relevant UI information according to the selected unit.

## Actual Result

The CMS/Inches toggle did not make any visible changes in the UI.

## Impact

A non-functional unit toggle can cause confusion for users and prevent them from viewing information in their preferred measurement format.
