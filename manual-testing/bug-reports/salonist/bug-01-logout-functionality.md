# SALO_P2_001 — Logout Functionality Not Working

## Bug Type
Functional

## Severity
Major

## Priority
High

## Environment
Android Mobile App

## Description

The logout functionality was not working as expected, preventing the user from properly ending the authenticated session.

## Steps to Reproduce

1. Open the Salonist Partner application.
2. Log in using a valid account.
3. Navigate to the logout option.
4. Tap the logout action.
5. Observe the application behavior.

## Expected Result

The user should be successfully logged out of the application.

After logout, the authenticated session should end and the user should be redirected to the appropriate login screen.

## Actual Result

The logout functionality did not work as expected.

## Impact

A non-functional logout mechanism can prevent users from securely ending their session and may create an inconsistent authentication experience.
