# Manual Testing — Bug Reports

This section contains selected examples of defects identified during my QA work.

The examples demonstrate:

- Defect identification
- Reproduction and investigation
- Clear expected vs actual results
- Severity and priority assessment
- Functional and UI/UX validation
- Cross-browser and cross-device testing
- Fix verification and regression testing

> Project-specific URLs, credentials, internal references and confidential information have been removed or generalized for confidentiality.

## Projects Represented

- Sierra Darien — E-commerce
- PartxFinder — Automotive Marketplace
- FR8NITY — Web Application
- Salonist Partner App — Mobile Application

## Bug Report Format

Each selected defect follows a structured format:

- Bug ID
- Title
- Severity
- Priority
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Testing Type
- Status
